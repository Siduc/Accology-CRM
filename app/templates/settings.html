{# ========== TASK PUSH API ========== #}

Outlook → Task push

Selective email → Accologise task

Chatter stays in Outlook. An Outlook button (or Power Automate) can POST /api/v1/tasks/from-email with an API key to create a Task. Accologise matches the sender to a Client when possible.

API key: {% if task_push_key_set %} Configured {% else %} Not set {% endif %}

Set TASK_IMPORT_API_KEY in the environment / .env, then restart. Power Automate header: X-API-Key: <your key> (no browser login). Contract: GET /api/v1/tasks/from-email

Outlook → Prospect (proposal emails)

Flag a sent proposal email (Power Automate / Outlook button) to POST /api/v1/prospecting/from-email (same API key). That will:

  • Log an email activity on the matched prospect
  • Set pipeline value when you pass estimated_value (e.g. 10000)
  • Create a follow-up task (default +7 days)
  • Store attachments in OneDrive: Accologise / Prospects / {Name} / Proposals

Match by To: email = prospect email, or pass prospect_id. Contract: GET /api/v1/prospecting/from-email
