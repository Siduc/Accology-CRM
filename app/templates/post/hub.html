How it works & best practice

  1. Scan a pile as one multi-page PDF (or many files). Import OCRs image-only scans, then auto-splits on letterheads (Dear…, HMRC, Companies House, Page 1 of N). Court packs stay together only when most pages are court paperwork — mixed post is not glued into one file.
  2. Import extracts text (pdfplumber + pypdf), splits into separate review items, suggests client (company number / name) and action (HMRC file · chaser email · review). Manual page split still available if auto-split misses.
  3. Review confirms or corrects client, then File / File as HMRC / Email client / Dismiss. Tick Learn this to save keywords → action as a rule.
  4. Wrong cut? Use Cut into letters: number of letters, then pages for each (or type 8x2, 2x1, 4, 2). It learns the logos and typefaces at each break for the next pile.
  5. For you to deal with (addressed to Accology Limited / Accology Pays, or client post you handle as agent): Review → File + create task. The task is linked to the letter.
  6. Email someone else (solicitor, HMRC, bank, colleague): on Review type the address → Email this address. The PDF is attached. That is not the client email button.
  7. HMRC standard letters usually file to the client Tax / Correspondence folder without emailing.
  8. Chasers / demands usually email the client (and optionally file a copy).
  9. Filing lives in OneDrive under Accology Documents / Clients / … (Microsoft must be connected).
  10. Local-only folder — Render cloud cannot see C:\accologise post. Run Import on the PC that receives scans (this app local or a small agent later).
  11. Other good practice: dual-control for bank detail changes; never email full ID docs without care; retain originals in done/; tag deadlines as tasks; link material post to the open job; separate personal practice post vs client post trays if the scanner allows two profiles.
