How it works & best practice

  1. Scan a pile as one multi-page PDF (or many files). Import auto-splits on letter markers (HMRC, Dear…, Form SA…, blank separator sheets) — same idea as the Ahmed invoice multi-pack splitter.
  2. Import extracts text (pdfplumber + pypdf), splits into separate review items, suggests client (company number / name) and action (HMRC file · chaser email · review). Manual page split still available if auto-split misses.
  3. Review confirms or corrects client, then File / File as HMRC / Email client / Dismiss. Tick Learn this to save keywords → action as a rule.
  4. Wrong pages in a letter? On Review, tick the stray pages under Wrong pages here? → move to holding. Open the correct document and Attach to start/end from the holding list.
  5. HMRC standard letters usually file to the client Tax / Correspondence folder without emailing.
  6. Chasers / demands usually email the client (and optionally file a copy).
  7. Filing lives in OneDrive under Accology Documents / Clients / … (Microsoft must be connected).
  8. Local-only folder — Render cloud cannot see C:\accologise post. Run Import on the PC that receives scans (this app local or a small agent later).
  9. Other good practice: dual-control for bank detail changes; never email full ID docs without care; retain originals in done/; tag deadlines as tasks; link material post to the open job; separate personal practice post vs client post trays if the scanner allows two profiles.
